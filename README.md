# PublicIP

PublicIP is a PowerShell module for getting information about your public IP address.

## Installation

Install the module from the PowerShell Gallery:

```powershell
Install-PSResource -Name PublicIP
Import-Module -Name PublicIP
```

## Documentation

Documentation is published at [psmodule.io/PublicIP](https://psmodule.io/PublicIP/).

Use PowerShell help and command discovery for module details:

```powershell
Get-Command -Module PublicIP
Get-Help <CommandName> -Examples
```
